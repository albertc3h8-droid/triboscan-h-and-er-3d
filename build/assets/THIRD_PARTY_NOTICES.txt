TriboScan3D application code (app/, gui/, runtime/, integration/, io_exports/,
result_store/) is delivered as compiled bytecode inside this portable folder.

No component is modified. No telemetry, network access, installer, registry
writes, or services are included. The program only reads user-selected
``*_analysis.txt`` folders and writes below its own program folder
(results/, cache/, logs/, config/).

If a license file is missing from ``licenses\``, contact the maintainers for the
upstream text before redistribution outside the originating organisation.
