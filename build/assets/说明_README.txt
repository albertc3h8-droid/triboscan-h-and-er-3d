TriboScan3D 1.0.0（UI v2）— Windows x64 便携版使用说明
============================================================

一、这是什么
  独立的 Windows 桌面程序：读取 Bruker 三维硬度测量导出的 *_analysis.txt
  数据文件夹，显示 Er / H 双面板三维图，查看切片与完整点云，导出带真实
  坐标的原始点表（CSV，可直接用 Excel 打开）、当前视图 PNG 和可重开的插值场（.tsr3）。
  本版是 UI v2：新布局、帮助浮层、参考层、切片插值和新的导出卡片。

二、免安装与移动
  1. 整个 TriboScan3D_Portable_Windows_x64 文件夹就是程序，
     不需要安装 Python，也不需要管理员权限。
  2. 请复制/移动“整个文件夹”；不要只拷 TriboScan3D.exe。
  3. 双击 TriboScan3D.exe 启动。
  4. TriboScan3D_console.exe 是同一程序的诊断版（带控制台输出），
     程序打不开时可先运行它，把控制台信息发给维护人员。
  5. 所有者/权限需允许在程序文件夹内创建 cache、results、logs；
     放在 Program Files 等只读目录会明确报错，不会偷偷写到别处。

三、系统条件
  - Windows 10 / Windows 11，64 位（x64）。
  - 需要支持 OpenGL 3.2 或更高的显卡驱动（VTK 9.7 的要求）。
  - 未在 Intel 核显、远程桌面、虚拟机环境中实测；这些环境可能
    因驱动/软件渲染而启动失败或显示异常，属于未承诺范围。
  - 屏幕：最低 1280×720（100% 缩放）；125% 缩放需 1600×900，
    150% 缩放需 1920×1080。窗口打开时会自动夹到桌面工作区，
    不会比屏幕任务栏区域更高；再小不再支持。
  - 未做数字签名，首次运行可能被 SmartScreen/杀毒软件提示，
    请交由本单位 IT 审核，不要自行关闭安全软件。

四、界面与操作
  1. 启动：程序先显示空白工作区，不弹文件选择框。中间卡片和顶栏都提供：
       “打开数据文件夹”：选择包含 *_analysis.txt 的文件夹
         （只读取该文件夹第一层，不修改、不写入原始数据）。
       “打开已导出结果”：直接打开之前导出的 .tsr3，或
         原始点 CSV（只显示实测点，不含插值场）。
     在任何选择框点“取消”都会回到空白工作区，不会退出程序；
     关闭窗口才退出。命令行 --data / --open-result 仍可直接打开。
  2. 双面板：左侧 Er、右侧 H；两块 3D 视图可用鼠标左键旋转、右键平移、
     滚轮缩放；“重置视图”恢复默认视角。
  3. 视图模式（左侧栏）：
       Normal  正常视图
       Locate  悬停测点查看数值
       Raw     全部实测深度
     上方“切片视图 / 完整云图”切换当前显示的是切片还是完整点云。
  4. 深度范围：Common（公共范围）或 Actual（各自范围）。
  5. 参考层（左侧栏）：Auto（自动识别）、Layers（分层显示）、
     Envelope（包络显示）；“切片以上淡雾”可减弱远处点。
  6. 切片插值（左侧栏）：
       Linear  最快，适合快速查看
       Cubic   更平滑的张量积插值
       TPS     默认；各向同性、精确过实测点，首次切面稍慢
     插值只影响显示，不改变存储场和导出数据。
  7. 深度控制：拖动滑条，或在数字框输入深度后按回车；
     直方图上的红线标出当前切片位置。
  8. 帮助：顶栏“?”或按 F1 打开帮助卡片；Esc、右上角 × 或点击遮罩关闭。
     界面语言可在顶栏“中文 / English”切换。
  9. 状态栏显示当前状态、读取/计算/渲染耗时、视图信息和版本号。

五、导出
  右侧“导出操作”有三张卡片，每张只写一种文件；先选好导出目录
  （可“浏览”选择），勾选“导出后打开文件夹”可在完成后直接打开。
    - 导出图片（PNG）：当前两个 3D 视图的干净图，不含界面控件。
    - 导出插值场（.tsr3）：保存插值场，之后可用“打开结果文件”重开，
      不需要重新计算。
    - 导出原始点（CSV）：只含实测点，单个 CSV 文件，可直接用 Excel 打开。
  命令行/无人值守方式还支持 --export-to 一次写出完整组合
  （PNG + CSV + .tsr3），详见交接文档。

六、输出与缓存位置（全部在程序文件夹内）
  results\   导出的 PNG/CSV/.tsr3、用户保存的结果
  cache\     同文件夹再次打开时的自动缓存（可删除，不影响源数据）
  logs\      运行日志（出错时把这里的日志发给维护人员）
  config\    非可执行配置（app.json）
  移动整个程序文件夹时，这些内容一起移动；删除程序文件夹即可清理。

七、已知限制与注意
  - TPS 首次切面约 0.4 秒（构建插值算子），之后切换深度约 10 毫秒；
    Cubic 约 40 毫秒。这是显示插值的开销，不影响存储数据。
  - TPS 是全局支撑，峰顶可能比 Cubic 略高（本次样例约 +0.1 GPa）；
    若需要更保守的峰顶，可切换 Cubic。
  - 帮助卡片在 1280×720 下内容较满且不能滚动；建议 1536×992 及以上。
  - VTK 默认字体不含中文字形：数据组名称含中文时，图内用 ASCII 短标识，
    完整中文名保留在 PNG 元数据（Dataset 字段）中；深度、单位、Er/H、
    视图/范围文字均为 ASCII，不受影响。
  - 本程序只做单数据集查看/导出；XY 切片 UI 与“排除测点后重算”UI
    为后续接口，本版不提供。

八、版本与完整性
  VERSION.txt     应用版本、构建时间、Python/VTK/PyVista/PyInstaller 版本
  SHA256SUMS.txt  包内每个文件的 SHA256（可按行校验）
  发布/复制后若怀疑文件损坏，请用 SHA256SUMS.txt 校验。
