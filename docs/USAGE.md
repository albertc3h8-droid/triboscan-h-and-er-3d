# TriboScan3D 便携版 / Portable TriboScan3D

单文件夹、无需安装的 Windows 三维硬度查看程序。所有路径都相对于程序所在文件夹；不写注册表，不修改原始测量数据。

## 启动

- `TriboScan3D.exe`：无控制台窗口，正常图形界面。
- `TriboScan3D_console.exe`：保留控制台，便于查看日志与退出码。

首次启动后选择包含 `*_analysis.txt` 的数据文件夹，或选择已保存的 `.tsr3` 结果文件。

## 界面语言

- 默认跟随 Windows 显示语言：中文 Windows 显示中文，其它语言显示英文。
- 右侧 `中文 / English` 按钮可随时切换，立即生效，无需重启。
- 选择保存在程序文件夹的 `config/settings.json`，整个文件夹可整体复制到其它电脑。
- 中文界面需要系统字体 `msyh.ttc`、`simhei.ttf` 或 `simsun.ttc`。若都找不到，程序自动回退英文并在状态行说明，避免显示方框。
- 载入/计算进度窗口与错误提示使用同一语言和同一 `config/settings.json`；在主窗口切换语言后，下一次载入即使用新语言。
- `nm`、`GPa`、`RAW`、`Er`、`H`、`Delaunay3D`、`CSV`、`Excel` 等专业词保持原样。

## 计算、保存与重开

- 打开数据文件夹后在后台计算三维场；计算期间状态行显示读入 / 计算 / 渲染耗时。
- 计算超过 5 秒时 `保存` 按钮可用；保存对话框默认写入程序文件夹的 `results/`，也可另选可写目录。
- 保存的 `.tsr3` 是自包含结果文件，可在没有原始数据文件夹时用 `载入` 直接打开，不重新构建三维场。
- 程序不会自动保存，也不会改写原始数据；自动缓存只写入程序文件夹的 `cache/`，可安全删除。
- 若保存失败，状态行和日志会给出完整目标路径、异常类型/`WinError` 及“改选可写目录或使用默认 results 目录”的建议；程序不会静默改变保存路径。

## 导出

- `导出` 同时生成原始测点 CSV、Excel 和当前帧 PNG 到 `results/run_<时间>/`。
- 导出成功后状态行显示完整导出目录；交互式界面会自动在资源管理器打开该 `run_` 文件夹。若资源管理器无法打开，导出仍然成功，状态行给出完整路径和失败提示。
- `--offscreen`、`--auto-close-ms` 以及带 `--export-to`/`--scene-report`/`--screenshot`/`--timings-json` 的自动化运行不会弹出资源管理器。
- CSV 包含真实 XYZ 坐标与来源文件/行号；PNG 文件名和图内页脚带实际切片深度 `heff`，并写入 PNG 文本元数据。
- RAW 模式导出所有实测深度，不代表单一切片；图内会明确标注 `not a single-depth slice`。

## 程序文件夹

| 路径 | 用途 |
| --- | --- |
| `config/` | 便携设置（语言偏好等） |
| `cache/` | 可重开的计算缓存，可删除 |
| `results/` | 用户保存的结果与导出文件 |
| `logs/` | 运行日志 |
| `_internal/` | 随附的 Python / VTK / PyVista 运行时，请勿修改 |

## 已知限制

- 三维坐标轴刻度在窄窗口、小字号下可能与轴标签靠得较近；这是既定显示限制，不影响数值。
- 本版本不提供 XY 平面切片和“排除测点后重算”的界面；底层接口已保留，调用时明确返回未实现，不会静默给出错误结果。
